# サブスクリプション支払料金管理アプリ 仕様書

## 📌 プロジェクト概要

ユーザーが管理するサブスクリプション（Netflix、Spotify、クラウドサービスなど）の支払い情報を一元管理し、月次レポートメール機能を通じて支払い情報を定期的に確認できるアプリです。

イベントソーシングを採用し、加入・解約・再開・値上げをイベントとして記録し、支払い履歴はそこから生成します（詳細は [01_概要仕様](./01_overview.md) / [02_データモデル](./02_data_model.md)）。

## 🎯 主要機能（予定）

### フェーズ1（MVP）
- [x] サブスクリプション登録・編集・削除
- [x] サブスクリプション一覧表示
- [x] イベント記録（加入 / 解約 / 再開 / 値上げ）
- [x] 過去の訂正（イベントの追加・編集）
- [x] 支払い履歴の自動生成（イベントからリプレイ）
- [x] 月別支払い合計表示
- [x] 次の更新日表示（next_renewal_on はリプレイから導出）
- [x] ドキュメントの複数添付（Active Storage）
- [x] 日次バッチ処理（当日までの支払いを最新化）

### フェーズ2
- [ ] 月次レポートメール送信
- [ ] 過去支払い履歴分析
- [ ] スケジューラー実装

### フェーズ3
- [ ] ダッシュボード・統計分析
- [ ] Excelエクスポート
