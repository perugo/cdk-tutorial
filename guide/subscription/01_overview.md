# 01. 概要仕様

## 機能名
サブスクリプション支払料金管理アプリ

## 概要

ユーザーが複数のサブスクリプションサービスを一元管理し、支払い情報を可視化・追跡するアプリです。ユーザーは個別のサブスクリプション情報を登録・編集し、月次通知メールで支払い情報を確認できます。

加入・解約・値上げといった出来事は「イベント（事実のログ）」として記録され、支払い履歴はそのイベントから自動生成されます。これにより「実はこの時期から加入していた」「この時期に値上げされていた」といった**過去の訂正**を、後からでも正確に反映できます。

## 対象ユーザー

- 複数のサブスクリプションサービスを利用している個人ユーザー
- 支払い情報を効率的に管理したい人

## 主要な課題（これを解決するアプリ）

1. 複数のサブスクリプション情報が散在している
2. 更新日（自動更新日）を忘れやすい
3. 月間支払い合計が不明確
4. 支払い履歴の追跡が困難
5. 加入時期・料金改定を後から正しく訂正しづらい

## コア機能

### 必須機能（MVP）

1. **サブスクリプション管理**
   - 登録：サブスクリプション情報の新規登録（加入イベントを記録）
   - 編集：既存情報の修正
   - 削除：不要なサブスクリプションの削除
   - 表示：登録されたサブスクリプション一覧表示

2. **イベント記録（加入・解約・再開・値上げ）**
   - 出来事を「いつ（effective_on）」「何が起きたか（event_type）」で記録
   - 過去の日付のイベントも追加・編集できる（遡及訂正）

3. **支払い情報表示**
   - 次の更新日表示
   - 月別支払い合計
   - サブスクリプション詳細情報表示
   - 支払い履歴はイベントから自動生成（再生成可能）

### 今後追加予定の機能

4. **月次通知メール**
   - 毎月定期的に支払い情報をメール送信
   - 更新予定日の事前通知

5. **分析・レポート**
   - 月別支払い推移グラフ
   - Excelエクスポート

## 設計方針（イベントソーシング）

- ユーザーが記録する正本は **イベント（`subscription_events`）** のみ。
- 支払い履歴（`subscription_payments`）は、イベントを時系列に再生（リプレイ）して生成する**派生データ（キャッシュ）**。
- 稼働区間（period）はテーブルとして持たず、リプレイ中に導出する。
- 過去を訂正したいときは、イベントを追加・編集して再投影（rebuild）するだけ。支払いログは自動で整合が取り直される。

## データ項目

### サービス定義（不変寄りの設定）

| 項目 | 型 | 説明 |
|------|------|------|
| name | String | サブスクリプション名（例：Netflix Premium） |
| provider_name | String | サービスプロバイダ名（例：Netflix） |
| billing_cycle | String | 課金サイクル（monthly / quarterly / yearly） |
| memo | Text | メモ・備考欄 |
| documents | Active Storage | 請求書などのドキュメント（複数添付可・`has_many_attached`） |

### イベント（時間とともに変わる事実）

| 項目 | 型 | 説明 |
|------|------|------|
| event_type | String | subscribed / price_changed / canceled / resumed |
| effective_on | Date | その事実が効力を持つ日 |
| price | Integer | 価格（subscribed / price_changed のときに設定） |

### 支払い（イベントから自動生成）

| 項目 | 型 | 説明 |
|------|------|------|
| paid_on | Date | 課金が発生した日 |
| amount | Integer | その時点の金額（円） |

## 技術スタック（予定）

- **バックエンド**: Ruby on Rails
- **フロントエンド**: Hotwire/Stimulus
- **データベース**: PostgreSQL（RDS）
- **メール送信**: Rails ActionMailer + 定期実行（Scheduler）
- **デプロイ**: AWS ECS + CloudFormation/CDK

## 注記

- 価格は JPY（円）固定・integer
- 詳細なデータモデルは `02_data_model.md` を参照
